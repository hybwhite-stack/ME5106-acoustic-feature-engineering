# 20 分钟以内的 PPT 路线

这是一门声学/制造相关课程的 Task 3b，重点是**本项目分割信号的物理启发特征工程**。最终任务只预测功率 P；已知速度 V 用于辅助特征探索。建议11页、约18分钟，给录制转场留余量。

| 页 | 标题与证据 | 建议时间 |
| ---: | --- | ---: |
| 1 | 问题：能否从打印声预测激光功率P？速度V作为辅助标签 | 0.5分钟 |
| 2 | 实验设置：麦克风、49组×5条Track、160 kHz采样 | 1.5分钟 |
| 3 | 原始连续录音的挑战：噪声、轨迹间空闲段、不同声包 | 1.5分钟 |
| 4 | 去噪：解释8 kHz高通并展示`figures/原始与8kHz高通对比.png` | 1.5分钟 |
| 5 | 分割：1 ms RMS与边界，展示第01/49组分割复核图 | 2分钟 |
| 6 | 物理问题推动三类特征：声强、频率分布、时间变化；显眼列出14项特征编号 | 2.5分钟 |
| 7 | 一条Track上具体怎样计算RMS、峰值、FFT频带占比、前/中段比 | 2分钟 |
| 8 | 五条Track各提特征再组内汇总；一组最终是一行 | 1.5分钟 |
| 9 | 用约1分钟讲训练：功率46组留一，速度探索47组留一且包含已知850 mm/s的49组 | 1分钟 |
| 10 | 功率A–E五组与速度V1–V6六组：P最高43/46在20%内，速度探索最高43/47分类正确；解释分段、时长和尾段的作用 | 2.5分钟 |
| 11 | 第49组预测功率383.18 W、已知速度850 mm/s、事后误差与新样本验证限制 | 1.5分钟 |

讲述顺序可以概括为“**信号怎样变得可用 → 为什么这样选特征 → 特征是否改善预测 → 预测能说到哪一步**”。第6–8页是核心。[功率与速度特征组合一览](五组特征组合一览.md)应直接变成清晰的特征表。第10页功率五组固定ElasticNet，速度六组固定逻辑回归；两者分别有46与47个已知标签组，不能写成相同训练样本数。第49组速度850 mm/s是已知值，不是最终预测；425 W参考下的9.84%功率误差是事后对照。图中的纵轴和单位、每条Track的前/中段窗口、声学边界状态，应在最终PPT前复核。
