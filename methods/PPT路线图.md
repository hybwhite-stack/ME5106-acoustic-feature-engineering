# 20 分钟以内的 PPT 路线

这是一门声学/制造相关课程的 Task 3b，重点是**信号与物理启发的特征工程**。模型只是最后把特征变成 P/V 的工具；不展示随机尝试很多算法的排行榜。建议11页、约17.5分钟，给录制转场留余量。

| 页 | 标题与证据 | 建议时间 |
| ---: | --- | ---: |
| 1 | 问题：能否从打印声推断激光功率P与扫描速度V？ | 0.5分钟 |
| 2 | 实验设置：麦克风、49组×5条Track、160 kHz采样 | 1.5分钟 |
| 3 | 原始连续录音的挑战：噪声、轨迹间空闲段、不同声包 | 1.5分钟 |
| 4 | 去噪：解释8 kHz高通并展示`figures/原始与8kHz高通对比.png` | 1.5分钟 |
| 5 | 分割：1 ms RMS与边界，展示第01/49组分割复核图 | 2分钟 |
| 6 | 物理问题推动三类特征：声强、频率分布、时间变化；显眼列出14项特征编号 | 2.5分钟 |
| 7 | 一条Track上具体怎样计算RMS、峰值、FFT频带占比、前/中段比 | 2分钟 |
| 8 | 五条Track各提特征再组内汇总；一组最终是一行 | 1.5分钟 |
| 9 | 用约1分钟讲预测：46组拟合，P是数值预测，V是分类，整组留出 | 1分钟 |
| 10 | 固定同一个功率模型比较A–E五组特征（6、5、8、11、14项），展示46组误差≤20%的36、37、40、35、42组；解释D为何反而下降 | 2分钟 |
| 11 | 三组预测、49号已见参考值、分割复核和新样本验证的限制 | 1.5分钟 |

讲述顺序可以概括为“**信号怎样变得可用 → 为什么这样选特征 → 特征是否改善预测 → 预测能说到哪一步**”。第6–8页是核心。[五组特征组合一览](五组特征组合一览.md)应直接变成一张清晰的特征表，不要只写“旧八项”。第10页的数据来自同一ElasticNet与同一整组留出方法，才适合讨论特征变化；不是模型之间的排行榜。第49组按425 W计算的8.85%是已见参考值后的对照，不能写成盲测。图中的纵轴和单位、每条Track的前/中段窗口、`NeedsVisualReview` 边界状态，应在制成最终PPT前复核。
