# 20 分钟以内的 PPT 路线

这是一门声学/制造相关课程的 Task 3b，重点是**本项目分割信号的物理启发特征工程**。最终任务只预测功率 P；已知速度 V 用于辅助特征探索。建议11页、约18分钟，给录制转场留余量。

| 页 | 标题与证据 | 建议时间 |
| ---: | --- | ---: |
| 1 | 问题：能否从打印声预测激光功率P？速度V作为辅助标签 | 0.5分钟 |
| 2 | 实验设置：麦克风、49组×5条Track、160 kHz采样 | 1.5分钟 |
| 3 | 原始连续录音的挑战：噪声、轨迹间空闲段、不同声包 | 1.5分钟 |
| 4 | 去噪：解释8 kHz高通并展示`figures/原始与8kHz高通对比.png` | 1.5分钟 |
| 5 | 分割：1 ms RMS与边界，展示第01/49组分割复核图 | 2分钟 |
| 6 | 物理问题推动三类特征：声强、频率分布、时间变化；显眼列出14项特征编号 | 2.5分钟 |
| 7 | 一条Track上具体怎样计算RMS、峰值、FFT频带占比、前/中段比 | 2分钟 |
| 8 | 五条Track各提特征再组内汇总；一组最终是一行 | 1.5分钟 |
| 9 | 用约1分钟讲训练：功率46组逐组留一，每轮45组训练、1组验证；速度探索另用47组 | 1分钟 |
| 10 | 功率A–E五组按留出成功率（误差≤20%）和MAPE选特征；E为43/46即93.48%、MAPE 8.05%；速度探索单独呈现 | 2.5分钟 |
| 11 | 用选中的特征在46组功率已知样本上重新拟合，只展示第49组预测 P，并说明未来新样本验证 | 1.5分钟 |

讲述顺序可以概括为“**信号怎样变得可用 → 为什么这样选特征 → 特征是否改善预测 → 预测能说到哪一步**”。第6–8页是核心。[功率与速度特征组合一览](五组特征组合一览.md)应直接变成清晰的特征表。第10页功率五组固定ElasticNet，并按46组留出成功率优先、MAPE次之排序；速度六组固定逻辑回归，使用47个已知速度组，另作探索。第49组速度850 mm/s是已知值，不是最终预测；第49组只展示预测功率 P。图中的纵轴和单位、每条Track的前/中段窗口、声学边界状态，应在最终PPT前复核。
