# 信号处理与特征定义

## 1. 数据与实验单位

课程给出一段连续录音，采样率 `Fs = 160000 Hz`。**当前仓库的特征与结果全部使用本项目自己的分割数据**：49组，每组5条单轨打印声事件，共245条 Track。五条是同一工况的重复观测；每条先提特征，再在组内汇总为一行。队友分割没有进入当前结果。

第41、43、49组的正式功率标签在任务标签表中为空；第49组扫描速度**已知为850 mm/s**，41、43组速度未知。课程说明图第4页另把49组写作425 W / 850 mm/s。425 W只用于预测后的事后误差核对，不进入功率模型训练。

## 2. 去噪与分割

按课程示意移除0–80 kHz单边频率范围底部10%：标称高通截止为8 kHz。`scripts/denoise_bottom10_and_plot.m` 使用801抽头线性相位 FIR 和分块 FFT 卷积；原始文件不改动。原始与去噪 `.mat` 已在本地保存，远端尚未上传大型波形文件。脚本会在输出文件已存在时停止，避免覆盖。

`scripts/segment_denoised_tracks.m` 在每个不重叠的1 ms窗口计算 RMS。全记录的中位数和未缩放 MAD 定义背景；高阈值为中位数＋30×MAD，低阈值为中位数＋6×MAD。持续至少5 ms的高阈值活动作为核心，再向两侧扩展至低阈值；相邻 Track 间隔超过0.100 s时分为下一组。生成器将重跑结果写到 `data/segmented_generated/`，不覆盖已提供的切片。25–50倍 MAD 的高阈值均检出245条/49组，但这不等于边界已由人工或激光触发时间戳确认。

## 3. 单条 Track 特征

设去噪后 Track 为 `x(1:N)`：

- 时域：`RMS = sqrt(sum(x.^2)/N)`；`PeakAbs = max(abs(x))`；峰峰值为 `max(x)-min(x)`。另计算最小值、最大值、算术均值和中位数。幅值沿用源信号单位，未校准为焦耳声能。
- 频域：仅为频谱计算从 Track 减去均值、乘周期 Hann 窗，取单边 `abs(FFT).^2` 功率。频谱中心为8–80 kHz内的 `sum(f.*P)/sum(P)`。
- 频带占比：8–20、20–40、40–80 kHz各段功率除以8–80 kHz总功率。当前功率14项仅使用8–20和40–80两段，避免三段占比完全重复。
- 起始尖峰比：0–2 ms最大绝对幅值除以5–25 ms绝对幅值的第99百分位。组级取五条中**最大两个比值的平均**；不固定为T1/T2。
- 前/中段变化：每条 Track 切0–10 ms和10–25 ms，计算两段RMS之比及两段40–80 kHz占比之差；之后在五条之间取**中位数**，作为当前功率14项的第13、14项。

`scripts/extract_denoised_track_features.m` 可从本地分割 `.mat` 重算基础时域和频谱特征。当前仓库发布预测所需的组级特征 CSV；波形级重提仍需要未上传的本地 `.mat`。

## 4. 五轨汇总与模型输入

六项基础时域统计先逐轨计算，再同名量取五轨平均。`PooledRMS` 将五条长度不同的波形采样点合起来算，因此通常不等于五个单轨 RMS 的普通平均。当前功率14项还包括平均绝对峰值、平均频谱中心、两个平均频带占比、最突出两条起始尖峰比，以及两个前/中段中位数。**功率模型不使用尾段衰减特征。** 全部14项与功率A–E、速度V1–V6组合见[特征组合清单](五组特征组合一览.md)。

这些特征并非14个独立物理因素：最小值、最大值和峰峰值有确定关系，`RMS_Mean` 与 `PooledRMS` 也高度相关。特征对照可说明当前数据中哪些信息与预测表现相关，不能直接证明熔池机理的因果关系。

## 5. 标签、训练与评价边界

功率模型固定为 `StandardScaler + ElasticNet(alpha=0.1, l1_ratio=0.3)`。46个功率已知组逐组留一；每轮标准化和拟合只看其余45组。按46组误差≤20%的组数及MAPE，当前选用14项中位数方案。全部46组重新拟合后预测41、43、49组功率；49组425 W参考值不进入任何功率拟合。

速度是辅助探索，固定 `StandardScaler + LogisticRegression(C=0.3)`。47个速度已知组（**含49组**）逐组留一；49组在自己的留出折不会参加训练，其余折可参加训练。探索完成后也用全部47组拟合速度模型，但最终结果表不把49组速度写成待预测值。已知的850 mm/s可辅助理解或挑选特征，不过49组留出命中已参与探索，不能称为独立盲测。

由于425 W和850 mm/s参考值以及平均/中位数候选此前已被看过，第49组功率误差只称作**事后参考误差**。真正的外部验证还需要冻结处理方法后采集新的未知标签组。
