# 信号处理与特征定义

## 1. 数据与实验单位

课程给出一段连续录音；采样率 `Fs = 160000 Hz`。最终分割为 49 组，每组 5 条单轨打印声事件，共 245 条 Track。五条属于同一组工艺参数，是重复观测；训练时先从每条提特征，再把同组特征汇总成一行。第 41、43、49 组的功率标签在任务用标签表中为空；第 49 组速度为 850 mm/s。课程说明图另在第 4 页把第 49 组写作 425 W / 850 mm/s，因此 425 W 只用于已见过参考值后的误差核对。

## 2. 去噪与分割

按课程示意移除 0–80 kHz 单边频率范围底部 10%：标称高通截止为 8 kHz。`scripts/denoise_bottom10_and_plot.m` 使用 801 抽头线性相位 FIR 和分块 FFT 卷积；原始文件不改动。去噪 `.mat` 已在本地准备，远端数据目录尚待上传。脚本为了防止覆盖已有结果，会在输出文件存在时停止。如需从头重算，先在独立工作目录准备原始数据与脚本。

`scripts/segment_denoised_tracks.m` 在每个不重叠的 1 ms 窗口计算 RMS。全记录的中位数和未缩放 MAD 定义背景；高阈值为中位数 + 30×MAD，低阈值为中位数 + 6×MAD。持续至少 5 ms 的高阈值活动作为核心，再向两侧扩展至低阈值；相邻 Track 间隔超过 0.100 s 时分为下一组。生成器将重新运行结果写到 `data/segmented_generated/`，不覆盖已经提供的切片。25–50 倍 MAD 的高阈值均检出245条/49组，但这个稳定性不等于人工边界验证。边界文件中的 `NeedsVisualReview` 状态仍保留。

## 3. 每条 Track 的基础特征

设去噪后 Track 为 `x(1:N)`：

- 强度：`RMS = sqrt(sum(x.^2)/N)`；`PeakAbs = max(abs(x))`；峰峰值为 `max(x)-min(x)`。另计算最小值、最大值、算术均值和中位数。强度单位沿用源信号幅值；平方幅值积分不等于经过传感器校准的焦耳声能。
- 频域：只为频谱计算从 Track 减去均值、乘周期 Hann 窗，取单边 `abs(FFT).^2` 功率。频谱中心为 `sum(f.*P)/sum(P)`，频率范围8–80 kHz。
- 频带占比：8–20 kHz 或40–80 kHz的频谱功率，分别除以8–80 kHz总功率。20–40 kHz是第三段，三段占比之和约为1；在旧八项中只使用8–20和40–80两段，避免完全重复。
- 起始尖峰比：本条 Track 的0–2 ms最大绝对幅值，除以5–25 ms绝对幅值的第99百分位。组级特征取五条中**最大的两个比值的平均**，它们不固定是T1/T2。
- 前/中段变化：对**每条 Track 自身**切0–10 ms前段、10–25 ms中段。计算两段RMS之比，以及两段40–80 kHz占比之差。之后才在五条之间取平均数或中位数。这里的“前/中段”不是一整组录音的前半段/中段。

基础数值可由 `scripts/extract_denoised_track_features.m` 从已保存的分割 `.mat` 重算。额外的六项时域、起始尖峰与前/中段结果也保存在 `data/features/` 逐轨和逐组 CSV 中。当前仓库的 MATLAB 基础脚本和 CSV 记录足以检查定义；新增的时段/尖峰特征尚未全部整理为单一 MATLAB 重算入口。

## 4. 五轨汇总与五组候选特征

对每组的五条 Track，六项时域统计（最小、最大、均值、中位数、峰峰值、RMS）逐条计算后，同名量在五条之间各取算术平均。旧八项为：整体 `PooledRMS`、五轨平均 `PeakAbs`、五轨平均频谱中心、五轨平均8–20及40–80 kHz占比、组级起始尖峰比、五轨前/中 RMS 比、五轨前/中高频占比差。`PooledRMS` 将五条长度不同的采样点共同计算，与五个 RMS 的普通平均不完全相等。

**所有14项的名称、计算方式，以及 A–E 五组各包含哪几项，见[五组特征组合一览](五组特征组合一览.md)。** A为六项时域，B为五项声强频谱，C为B加上起始尖峰和前/中变化，D为A与B合并，E为全部14项。联合输入有14列，但不等于14条独立物理规律。例如最小值、最大值、峰峰值之间有确定关系，两个RMS也高度相关。我们用同一个预测器对五组输入进行对照，回答不同类型的声学信息是否能改善当前组级预测；不能由预测增益直接证明熔池中的某个因果机制。

## 5. 标签和预测边界

`scripts/join_sample_features_with_labels.m` 记录课程图示到 SampleID 的标签映射。46组功率、速度均已知，参加训练；41、43、49的功率未知，41、43的速度未知。当前预测程序对46组作按SampleID逐组留出，每轮只在另外45组拟合特征标准化与模型。第49组课程材料中的425 W不进入训练。反复看过这个参考值后挑选平均数版本，所以第49组误差应称作**事后参考误差**；真正的外部验证仍需新的未见标签组。
