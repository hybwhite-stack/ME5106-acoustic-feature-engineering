# ME5106 Task 3b：从打印声信号提取特征并预测 P/V

本仓库按课程汇报的研究逻辑组织：**数据 → 8 kHz 高通 → 打印轨迹分割 → 声学特征 → 五轨汇总 → 参数预测**。重点是信号处理、特征的物理含义和它们在同一评价口径下的贡献；机器学习仅用于将组级特征映射到激光功率 P（W）和扫描速度 V（mm/s）。这里没有搬入旧仓库的大量模型搜索实验。

**上传状态：当前先发布方法、脚本、图示和结果；`data/` 数据集目录暂未上传。** 因此当前远端版本的预测脚本尚不能单独运行，需等数据上传完成。完整数据已在同名本地工作目录整理好，并经 SHA-256 核对，三个较大的 `.mat` 文件将通过 Git LFS 上传。

仓库当前设为**私有**。原始 `.mat` 是课程提供的数据，未声明可公开再分发的许可证；请勿在确认授权前将本仓库改为公开。数据上传完成后，克隆仓库还需运行 `git lfs pull` 才能得到完整 `.mat`，而不是指针文件。

采样率为 160 kHz，奈奎斯特频率为 80 kHz。课程材料提出移除频率范围底部 10%；这里以 **8 kHz** 为高通的标称截止频率。分割用 1 ms RMS 检测声学活动，排除打印间空闲段。边界是声学估计，尚未由激光触发时间戳独立确认；原边界表保留 `NeedsVisualReview` 状态。每组五条 Track 是同一工况的重复轨迹，训练的独立单位是 **46 个已完整标注的 SampleID**。

## 目前能复核的结果

固定 `StandardScaler + ElasticNet` 和相同的 46 组整组留出方法，特征对照为：

| 功率输入特征 | 46 组相对误差 ≤20% | 46 组 MAPE | 第 49 组 P |
| --- | ---: | ---: | ---: |
| 六项时域统计 | 36/46 | 10.54% | 328.60 W |
| 旧八项，前/中段特征取五轨平均 | 40/46 | 9.23% | 385.83 W |
| 六项＋旧八项，共14项 | **42/46** | **8.30%** | **387.38 W** |

速度单独使用组级特征与逻辑回归，46 组整组留出正确 **42/46**。当前统一方案的输出为：

| SampleID | 预测 P | 预测 V | 状态 |
| ---: | ---: | ---: | --- |
| 41 | 333.89 W | 700 mm/s | 正式真值未公布 |
| 43 | 427.36 W | 550 mm/s | 正式真值未公布 |
| 49 | 387.38 W | 850 mm/s | 课程材料另给 425 W / 850 mm/s 作事后参考 |

按材料中的 425 W 计算，第 49 组功率相对误差为 **8.85%**。由于 425 W 已被看过，并参与过平均数/中位数方案的比较，这个数值**不是完全盲测的泛化准确率**。第 41、43 组不能计算误差。完整结果与模型边界见[结果解释](results/结果解释.md)。

## 复现与汇报

数据目录上传完成后，在仓库根目录安装 `requirements.txt` 中的包，运行：

```bash
python scripts/group_feature_prediction.py
```

脚本仅用46个完整标注组拟合；每轮留出整个 SampleID，所有标准化在训练组内完成。它重算固定模型的特征消融、46组逐组预测和三个待预测组的统一输出。原始波形的处理方法、数学定义和重跑 MATLAB 脚本的注意事项见[方法与特征](methods/信号处理与特征定义.md)。20分钟以内的讲述顺序见[PPT路线图](methods/PPT路线图.md)。
