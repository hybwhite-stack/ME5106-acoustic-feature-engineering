# ME5106 Task 3b：从打印声信号提取特征并预测 P/V

本仓库按课程汇报的研究逻辑组织：**数据 → 8 kHz 高通 → 打印轨迹分割 → 声学特征 → 五轨汇总 → 参数预测**。重点是信号处理、特征的物理含义和它们在同一评价口径下的贡献；机器学习仅用于将组级特征映射到激光功率 P（W）和扫描速度 V（mm/s）。这里没有搬入旧仓库的大量模型搜索实验。

## ⭐ 先看：功率五组、速度六组特征到底用了什么

**[功率五组、速度六组：逐项特征名称、定义和组合清单](methods/五组特征组合一览.md)**。功率的五组是 **A 六项时域（1–6）、B 五项声强频谱（7–11）、C 在B上加尖峰和前/中变化（7–14）、D 合并A与B（1–11）、E 全部联合（1–14）**。速度的六组 V1–V6 逐步比较时域、频谱、起始/前中变化、时长和尾段，最终使用18项。P和V各自固定一个模型，只比较输入特征；这里是特征对照，不是模型排行榜。特征按同一工况五条 Track 汇总，每组最终一行；第7项直接对五条的采样点合算 RMS。

## 目前能复核的结果

固定 `StandardScaler + ElasticNet` 和相同的 46 组整组留出方法，五组特征对照为：

| 功率输入特征 | 46 组相对误差 ≤20% | 46 组 MAPE | 第 49 组 P |
| --- | ---: | ---: | ---: |
| A 六项时域（1–6） | 36/46 | 10.54% | 328.60 W |
| B 五项声强频谱（7–11） | 37/46 | 10.60% | 335.58 W |
| C 八项，B＋尖峰与分段（7–14） | 40/46 | 9.23% | 385.83 W |
| D 十一项，A＋B（1–11） | 35/46 | 10.84% | 334.54 W |
| E 十四项，D＋尖峰与分段（1–14） | **42/46** | **8.30%** | **387.38 W** |

D 比 A 或 B 单独使用更差，说明把特征直接堆在一起未必有效；C、E 的表现提示起始与前/中段变化值得重点讨论。这里是预测对照，不是因果证明。具体列名已写在[结果 CSV](results/固定ElasticNet特征消融.csv)的“具体特征列名”列。

速度固定 `StandardScaler + LogisticRegression(C=0.3)`，以相同的46组整组留出比较六组输入：

| 速度输入特征 | 正确组数 | 平衡准确率 |
| --- | ---: | ---: |
| V1 六项时域 | 25/46 | 46.95% |
| V2 五项声强频谱 | 25/46 | 46.18% |
| V3 八项，增加起始与前/中变化 | 35/46 | 73.44% |
| V4 十四项，联合基础特征 | 34/46 | 70.88% |
| V5 十六项，增加时长 | 39/46 | 84.55% |
| V6 十八项，再加尾段 | **42/46** | **92.46%** |

三类速度在46组中各有12、21、13组；六种特征对第49组都预测850 mm/s。逐类结果与各组合完整特征列见[结果解释](results/结果解释.md)及[速度对照 CSV](results/固定逻辑回归速度特征对照.csv)。当前统一方案的输出为：

| SampleID | 预测 P | 预测 V | 状态 |
| ---: | ---: | ---: | --- |
| 41 | 333.89 W | 700 mm/s | 正式真值未公布 |
| 43 | 427.36 W | 550 mm/s | 正式真值未公布 |
| 49 | 387.38 W | 850 mm/s | 课程材料另给 425 W / 850 mm/s 作事后参考 |

按材料中的 425 W 计算，第 49 组功率相对误差为 **8.85%**。由于 425 W 已被看过，并参与过平均数/中位数方案的比较，这个数值**不是完全盲测的泛化准确率**。第 41、43 组不能计算误差。完整结果与模型边界见[结果解释](results/结果解释.md)。

## 复现与汇报

数据目录上传完成后，在仓库根目录安装 `requirements.txt` 中的包，运行：

```bash
python scripts/group_feature_prediction.py
```

脚本仅用46个完整标注组拟合；每轮留出整个 SampleID，所有标准化在训练组内完成。它重算功率五组、速度六组特征对照、逐组预测和三个待预测组的统一输出。原始波形的处理方法、数学定义和重跑 MATLAB 脚本的注意事项见[方法与特征](methods/信号处理与特征定义.md)。20分钟以内的讲述顺序见[PPT路线图](methods/PPT路线图.md)。
