# ME5106 Task 3b：从打印声信号预测激光功率

本仓库按“连续信号 → 8 kHz 高通 → 49组打印轨迹分割 → 声学特征 → 五轨汇总 → 功率预测”组织。**当前模型与结果全部使用本项目自己的分割数据**；队友的分割未进入本仓库当前结果。每组有5条重复 Track，训练的独立单位是 SampleID。最终目标是预测激光功率 P（W）；扫描速度 V（mm/s）作为已知标签用于辅助特征探索。

## 当前输入与标签

[功率和速度特征组合的逐项定义](methods/五组特征组合一览.md)列出功率 A–E 五组和速度 V1–V6 六组。当前功率方案 E 使用14项时域、声强、频谱、起始及前/中段特征，其中两项前/中段特征取五轨**中位数**，不含尾段衰减。功率模型固定为 `StandardScaler + ElasticNet(alpha=0.1, l1_ratio=0.3)`。

46组功率已知，41、43、49组功率留出。47组速度已知，**第49组速度为850 mm/s**，可参加速度探索的训练；41、43组速度未知。第49组的425 W来自已看过的课程图示，仅用于预测后的事后误差对照，不进入功率训练、标准化或留一验证。

## 功率：固定 ElasticNet，46组整组留一

| 输入特征 | 相对误差≤20% | MAPE | 第49组预测 P |
| --- | ---: | ---: | ---: |
| A 六项时域 | 36/46 | 10.54% | 328.60 W |
| B 五项声强频谱 | 37/46 | 10.60% | 335.58 W |
| C 八项：B＋尖峰与前/中变化 | 41/46 | 9.35% | 380.37 W |
| D 十一项：A＋B | 35/46 | 10.84% | 334.54 W |
| **E 十四项：D＋尖峰与前/中变化** | **43/46** | **8.05%** | **383.18 W** |

C、E 的分段项都使用五轨中位数。E 按46组内部功率表现选为当前方案；第49组的已见参考功率没有参与此排名。逐项输入见[特征消融 CSV](results/固定ElasticNet特征消融.csv)，逐组预测见[46组功率留一结果](results/46组功率逐组留出.csv)。

## 速度：辅助探索，49组已知速度可训练

速度采用单独的 `StandardScaler + LogisticRegression(C=0.3)`，仅用于比较特征，不作为第49组的最终待预测目标。47个速度已知组均参与逐组留一；轮到49组时，它的850标签在该折训练中被留出。全部47组拟合的探索模型则包含第49组。

| 速度特征 | 留一正确组数 | 平衡准确率 |
| --- | ---: | ---: |
| V1 六项时域 | 24/47 | 44.05% |
| V2 五项声强频谱 | 26/47 | 48.02% |
| V3 八项：加入尖峰与前/中变化 | 36/47 | 73.81% |
| V4 十四项联合 | 35/47 | 71.43% |
| V5 十六项：增加时长 | 40/47 | 84.92% |
| V6 十八项：再加尾段 | **43/47** | **92.46%** |

六组特征在49组单独留出的折中均给出850 mm/s。这是**已知速度参与探索后的留一诊断**，可辅助理解特征，但不能作为独立盲测成绩，也不用于计算最终功率误差。完整结果见[速度特征对照](results/固定逻辑回归速度特征对照.csv)和[47组逐组留一](results/47组速度逐组留出.csv)。

## 当前最终输出：只预测功率

| SampleID | 预测功率 P | 已知速度 V | 说明 |
| ---: | ---: | ---: | --- |
| 41 | 321.25 W | 未知 | 功率真值未公布 |
| 43 | 396.35 W | 未知 | 功率真值未公布 |
| **49** | **383.18 W** | **850 mm/s** | 速度已知，功率预测 |

按已见的425 W参考值计算，第49组功率事后相对误差为 **9.84%**。平均数和中位数方案此前都曾被研究，所以这个数字不能称作完全盲测的泛化准确率。[结果解释](results/结果解释.md)记录评价边界与完整输出。

## 复现

在仓库根目录安装 `requirements.txt` 中的依赖并运行：

```bash
python scripts/group_feature_prediction.py
```

每一轮标准化和模型拟合仅使用该轮训练组。脚本重算功率与速度的特征对照、逐组结果以及41、43、49组的功率预测；第49组速度列仅记载已知的850 mm/s。[PPT路线图](methods/PPT路线图.md)给出汇报顺序。
