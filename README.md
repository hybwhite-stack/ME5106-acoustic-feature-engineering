# ME5106 Task 3b：从打印声信号预测激光功率

本仓库按“连续信号 → 8 kHz 高通 → 49组打印轨迹分割 → 声学特征 → 五轨汇总 → 功率预测”组织。**当前模型与结果全部使用本项目自己的分割数据**；队友的分割未进入本仓库当前结果。每组有5条重复 Track，训练的独立单位是 SampleID。最终目标是预测激光功率 P（W）；扫描速度 V（mm/s）作为已知标签用于辅助特征探索。

## 当前输入与标签

[功率和速度特征组合的逐项定义](methods/五组特征组合一览.md)列出功率 A–E 五组和速度 V1–V6 六组。当前功率方案 E 使用14项时域、声强、频谱、起始及前/中段特征，其中两项前/中段特征取五轨**中位数**，不含尾段衰减。功率模型固定为 `StandardScaler + ElasticNet(alpha=0.1, l1_ratio=0.3)`。

46组功率已知，41、43、49组的功率留出。47组速度已知，**第49组速度为850 mm/s**，可参加速度探索的训练；41、43组速度未知。未知功率不进入特征选择、标准化或训练。

原始连续信号、去噪信号和245条分割波形的三个大型 `.mat` 文件目前未上传；当前预测脚本直接读取已发布的派生特征 CSV，可以重跑下面的结果。波形级重提特征仍需要本地 `.mat` 文件。[信号处理与特征定义](methods/信号处理与特征定义.md)说明 160 kHz 采样、8 kHz 高通和 1 ms RMS 分割。边界由声学活动估计，尚未用激光触发时间戳独立确认。

## 功率：用已知组留出结果选特征

功率固定 `StandardScaler + ElasticNet(alpha=0.1, l1_ratio=0.3)`。46轮验证中，每轮完整留出一个**功率已知**的 SampleID，用其余45组训练，再对留出组预测。将46次预测汇总后，先按相对误差≤20%的**成功率**选特征；成功率并列时比较 **MAPE**（46个留出组相对误差的平均值），仍并列时选较少特征。模型和标准化在每轮只用训练组拟合。

| 输入特征 | 留出成功组数 | 成功率 | MAPE |
| --- | ---: | ---: | ---: |
| A 六项时域 | 36/46 | 78.26% | 10.54% |
| B 五项声强频谱 | 37/46 | 80.43% | 10.60% |
| C 八项：B＋尖峰与前/中变化 | 41/46 | 89.13% | 9.35% |
| D 十一项：A＋B | 35/46 | 76.09% | 10.84% |
| **E 十四项：D＋尖峰与前/中变化** | **43/46** | **93.48%** | **8.05%** |

C、E 的前/中段两项使用五轨中位数。按上述规则选中 E；随后用全部46个功率已知组重新拟合，才对未知功率组预测。[特征消融 CSV](results/固定ElasticNet特征消融.csv)只记录已知组验证指标；[逐组留出结果](results/46组功率逐组留出.csv)保留46组各自的预测与误差。以上成功率是当前候选集上的内部留出结果，选特征后可能略偏乐观。

## 速度：辅助探索，49组已知速度可训练

速度采用单独的 `StandardScaler + LogisticRegression(C=0.3)`，仅用于比较特征，不作为第49组的最终待预测目标。47个速度已知组均参与逐组留一；轮到49组时，它的850标签在该折训练中被留出。全部47组拟合的探索模型则包含第49组。

| 速度特征 | 留一正确组数 | 平衡准确率 |
| --- | ---: | ---: |
| V1 六项时域 | 24/47 | 44.05% |
| V2 五项声强频谱 | 26/47 | 48.02% |
| V3 八项：加入尖峰与前/中变化 | 36/47 | 73.81% |
| V4 十四项联合 | 35/47 | 71.43% |
| V5 十六项：增加时长 | 40/47 | 84.92% |
| V6 十八项：再加尾段 | **43/47** | **92.46%** |

六组特征在49组单独留出的折中均给出850 mm/s。已知速度仅作辅助探索，不用于计算功率留出成功率或 MAPE。完整结果见[速度特征对照](results/固定逻辑回归速度特征对照.csv)和[47组逐组留一](results/47组速度逐组留出.csv)。

| SampleID | 预测功率 P |
| ---: | ---: |
| 41 | 321.25 W |
| 43 | 396.35 W |

第49组只报告预测功率；不计算该组的功率误差。[结果解释](results/结果解释.md)记录评价方法与完整输出。

## 复现

在仓库根目录安装 `requirements.txt` 中的依赖并运行：

```bash
python scripts/group_feature_prediction.py
```

脚本重算功率与速度的特征对照、逐组留出指标，并按成功率和 MAPE 自动选择功率特征，再输出41、43、49组的预测功率。[PPT路线图](methods/PPT路线图.md)给出汇报顺序。
